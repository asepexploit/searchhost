Deteksi File Duplikat
Kalau ada pesan yang isinya file yang PERSIS SAMA (dicek dari ID file bawaan Telegram, bukan cuma nama file) dengan yang sudah pernah didownload sebelumnya -- misal pesan lama di-forward/dikirim ulang -- file itu dilewati, gak didownload lagi. Deteksinya instan (dari metadata pesan, sebelum download apa pun jalan), jadi gak nambah beban. Catatan: cuma nangkep kasus forward/kirim-ulang pesan yang sama; kalau orangnya upload ULANG file dari perangkatnya sendiri (walau isinya identik), Telegram anggap itu file baru dan tetap bakal didownload.
Auto-fetch File dari Link Eksternal
Beberapa channel post file bukan lewat attachment langsung, tapi lewat tombol "DOWNLOAD FROM BOT" yang buka chat ke bot lain lalu kirim /start. Kalau diaktifkan, akun ini otomatis ikut alur itu (buka bot, kirim /start, klik tombol lanjutan kalau ada) dan download file yang dibalas. Karena ini artinya akun kamu otomatis DM bot pihak ketiga, defaultnya nonaktif.
Kalau pesan ada link gofile.io/d/... (di teks atau tombol) dan tidak ada file langsung, ambil isinya lewat API gofile lalu download file yang cocok ekstensi (mis. .txt). Tidak resmi/reverse-engineered -- bisa berhenti jalan kalau gofile ubah struktur API-nya.

Kirim Semua File di 1 Folder ke API
Buat kirim file .txt yang UDAH ADA di suatu folder (mis. numpuk dari sebelum toggle "Kirim ke API" dinyalain) -- bukan nunggu batch auto-extract baru. Pilih dulu folder INDUK-nya (hasil ekstraksi parsed_data/, atau file mentah hasil auto-download download/), baru isi subfolder-nya (mis. "leemek", atau "9-5-2026" buat folder tanggal). Tiap file yang KEKIRIM SUKSES otomatis DIHAPUS dari lokal -- yang gagal kirim TETAP DIBIARKAN.
